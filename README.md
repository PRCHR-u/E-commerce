# E-commerce Project

Проект для управления электронной коммерцией с классами Product и Category.

## Функциональность

Проект предоставляет следующие возможности:

*   **Управление продуктами:**
    *   Создание объектов `Product` с атрибутами: `name`, `description`, `price`, `quantity`.
    *   Изменение цены продукта.
    *   Получение строкового представления продукта.
    *   Сложение товаров одного типа для вычисления общей стоимости.
*   **Управление категориями:**
    *   Создание объектов `Category` с атрибутами: `name`, `description`, `products`.
    *   Добавление и удаление продуктов из категории.
    *   Подсчет общего количества категорий и продуктов.
    *   Получение строкового представления категории.
*   **Наследование:**
    *   Реализованы классы-наследники `Smartphone` и `LawnGrass` от `Product`.
    *   Добавление новых атрибутов в классы-наследники.
*   **Проверка типов:**
    * Проверка, что складываются только объекты одинакового типа.
## Установка

## ReprMixin

Добавлен класс миксин `ReprMixin`, который предоставляет дополнительную функциональность для классов, в которые он включен. Когда создается новый объект класса, унаследованного от `ReprMixin`, в консоль выводится информация о классе и параметрах, с которыми был создан объект. Также, класс `ReprMixin` предоставляет реализацию магического метода `__repr__`, что позволяет получить строковое представление объекта.




1. Убедитесь, что у вас установлен Poetry
2. Клонируйте репозиторий
3. Установите зависимости:
```bash
poetry install
```

## Использование

```python
from src.models import Product, Category

# Создание продукта
product = Product(
    name="Телефон",
    description="Смартфон последнего поколения",
    price=999.99,
    quantity=10
)

# Создание категории
category = Category(
    name="Электроника",
    description="Все виды электронных устройств",
    products=[product]
)
```
